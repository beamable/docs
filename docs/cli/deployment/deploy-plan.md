# Deploy plan

## Overview

The `beam deploy plan` command creates a deployment plan for your Beamable microservices. This command analyzes your local environment and generates a plan that shows what changes will be made when deploying to your remote environment.

## Prerequisites

You need:
- A configured Beamable project
- Docker installed and running
- Valid Beamable credentials
