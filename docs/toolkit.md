# Toolkit

The Beamable Toolkit defines the interface between the [Beamable Console](./console.md) and [MicroViews](./microapp.md). 

The Toolkit is available on NPM, 
[https://www.npmjs.com/package/@beamable/portal-toolkit](https://www.npmjs.com/package/@beamable/portal-toolkit)

```sh
npm install @beamable/portal-toolkit
```
