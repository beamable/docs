# Deploy release

## Overview

The `beam deploy release` command executes a deployment of your Beamable microservices to the remote environment. This command builds and deploys your services based on the configuration you specify.

## Prerequisites

You need:
- A configured Beamable project
- Docker installed and running
- Valid Beamable credentials
- Optionally, a deployment plan from `beam deploy plan`
