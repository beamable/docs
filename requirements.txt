# Pinned Python toolchain for building and publishing these docs.
#
# WHY THIS FILE EXISTS: setup.sh previously installed every dependency
# unpinned, so the CI toolchain could change with nobody touching the repo.
# It did. mkdocs-literate-nav 0.6.3 added a dependency on `properdocs` (the
# continuation of MkDocs, which has had no release since 2024), and from that
# release onward every CI run silently built with ProperDocs instead of
# MkDocs, while contributors with older virtualenvs kept building with MkDocs.
# The divergence went unnoticed for roughly three months. Pin, and changes
# arrive as a reviewable diff instead of a surprise in a commit message.
#
# NOTE: properdocs is what actually builds the site. It is listed below as a
# transitive dependency because that is how it currently enters the tree, via
# mkdocs-literate-nav. Promoting it to a direct dependency and renaming
# mkdocs.yml to properdocs.yml is tracked separately.
#
# TO REGENERATE after changing a direct dependency below:
#   pip install --dry-run --ignore-installed --report report.json <direct deps>
# then rewrite the pins from report.json.
#
# NOT HASH-PINNED, deliberately. Several of these ship platform-specific
# wheels, so hashes captured on one OS break installs on another. Doing it
# properly needs `pip-compile --generate-hashes`, which collects every
# platform's hash per version. Tracked as follow-up work.
